# Procyon sürümleri

Procyon, ağ mühendisleri için not alma, config inceleme ve troubleshoot dokümantasyonu uygulamasıdır (Windows).

Bu depo yalnız kurulum dosyalarını ve otomatik güncelleme bilgisini barındırır. Son sürümü [Releases](../../releases/latest) sayfasından indirin: `Procyon_<sürüm>_x64-setup.exe`.

- Yönetici izni gerekmez; yalnız sizin kullanıcınıza kurulur.
- Kurulum dosyası kod imzalama sertifikasıyla imzalı olmadığından Windows SmartScreen uyarabilir: "Ek bilgi" → "Yine de çalıştır".
- Kurulu Procyon yeni sürümleri bu depodaki `latest.json` dosyasından denetler ve yalnız Procyon anahtarıyla imzalanmış paketleri kurar.
